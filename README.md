# CITY POWDER ❄ — Urban Snowboard Odyssey

雪に覆われた街を、スノーボードで駆け抜ける 3D アクションゲーム。
ネオン街・夕陽の摩天楼・オーロラの古都という 3 つの街を舞台に、
キッカーでのビッグエア、スピン／フリップ／グラブ、レールグラインド、コンボを決めてハイスコアを狙います。

ブラウザだけで動作します（Three.js / WebGL2）。

## 遊び方

```bash
npm install
npm run dev      # http://localhost:5173 で起動
npm run build    # dist/ に本番ビルド
```

### 操作

| 操作 | キーボード | ゲームパッド |
| --- | --- | --- |
| カーブ（カービング） | ← → / A D | 左スティック |
| クラウチ（加速） | ↑ / W | 左スティック上 |
| ブレーキ | ↓ / S | 左スティック下 |
| オーリー | SPACE を長押しでため → 離してジャンプ | A |
| スピン（空中） | ← → | 左スティック左右 |
| フリップ（空中） | ↑ フロント / ↓ バック | 左スティック上下 |
| グラブ | J インディ / K メソッド / L ノーズ / I テール | X / B / Y / LB・RB |
| ポーズ | ESC / P | START |

スマートフォンではバーチャルスティックと JUMP / GRAB / TWEAK ボタンで操作できます。

### スコアのコツ

- 着地は**板の向きを進行方向（または逆向き＝スイッチ）にそろえる**こと。ずれていると転倒します。
- ボタンを離すと回転は自動的に最寄りの着地角度へ収束します。
- 着地後 3 秒以内に次のトリックを決めると**コンボ倍率**が上がります（地面にいる間だけゲージが減ります）。
- 角度ピッタリで着地すると **PERFECT ★** ボーナス。
- 壁（クォーターパイプ状のバンク）を駆け上がるとウォールエアが出せます。
- 階段の手すり、レール、レッジでグラインド。雪の結晶を集めるとボーナス。

## 特徴

- **3 つの街（ステージ）** — すべて手続き生成
  - `NEON SHINJUKU` 真夜中のネオン街。縦看板、ビジョン、電線、自販機、提灯
  - `GOLDEN SKYLINE` 夕陽の超高層ビル群。長い影、ガラスの照り返し、イルミネーションの木
  - `AURORA OLD TOWN` 吹雪の古都。町家、灯籠、提灯、雪山、オーロラ
- **3 人のライダー** — KAI / YUKI / REN。外見（ヘルメット・ビーニー・フード、ポニーテールやマフラーの物理揺れ）と性能が異なります。手足は 2 ボーン IK で、グラブでは実際に手が板をつかみます。
- **グラフィック**
  - HDR レンダリング + ACES トーンマッピング、ブルーム、MSAA
  - ライダーに追従するシャドウマップ、近くの街灯・看板を動的ポイントライトに割り当て
  - 窓の点灯・カーテン・雪の窓枠・店舗をすべてシェーダーで生成するビル群
  - 視差でキラキラ光る雪面、滑走跡、雪しぶき、火花、GPU 降雪
  - 星空・月・雲・オーロラ（三角ノイズのレイマーチ）のスカイシェーダー
  - スピードブラー、色収差、スピードライン、カラーグレーディング、フィルムグレイン
- **プロシージャルサウンド** — 風切り音・カービング音・グラインド音と、ステージごとに異なる生成 Lo-Fi BGM

## グラフィック設定

ポーズメニューの `GRAPHICS` で HIGH / MEDIUM / LOW を切り替えられます（ページが再読み込みされます）。
URL パラメータ `?q=low` でも指定できます。

## デバッグ用 URL パラメータ

| パラメータ | 内容 |
| --- | --- |
| `?stage=neon\|golden\|aurora` | ステージを指定 |
| `?rider=kai\|yuki\|ren` | ライダーを指定 |
| `?play` | タイトルを飛ばしてすぐに滑走開始 |
| `?autoplay` | 簡易ボットが自動で滑走 |
| `?inspect` | キャラクター確認用カメラ |

## デプロイ

`main` ブランチへ push すると GitHub Actions（`.github/workflows/deploy.yml`）が GitHub Pages にデプロイします。
リポジトリの **Settings → Pages → Source** を「GitHub Actions」に設定してください。

## 構成

```
src/
  main.js            ゲーム全体の状態管理・ループ・スコア
  core/              入力、プロシージャルオーディオ、ユーティリティ
  world/             ステージ定義、コース（地形・キッカー・レール）、街の生成
  player/            キャラクターモデル（IK・ポーズ）、ライダー物理とトリック判定
  gfx/               マテリアル／シェーダー、テクスチャ生成、ポストエフェクト、カメラ
  fx/                パーティクル、降雪、滑走跡
  ui/                メニュー・HUD・タッチ操作
```
